# QoO Application Profiles

The profiles in this directory are used to define QoO scoring thresholds for different application categories. 
Each profiles specifies the thresholds as defined in the [QoO draft](https://datatracker.ietf.org/doc/draft-ietf-ippm-qoo/).
The profiles prefixed with `libreqos-` are based on the [LibreQoS Internet Quality Test](https://test.libreqos.com/advanced/).
